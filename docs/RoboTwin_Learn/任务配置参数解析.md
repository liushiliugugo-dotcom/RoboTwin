🎬 1. 全局与导演指令 (Global Settings)
这部分控制了整个数据采集循环的宏观行为。

render_freq: 20

作用： 控制仿真渲染的频率。设为 20 意味着物理引擎每运算 20 步（Step），才向屏幕绘制一帧图像。设为 0 就是纯黑盒后台运算（速度极快）。

联动： 在第一阶段“探路”时起作用，让你可以肉眼看到机器人的试错过程。

episode_num: 3

作用： 目标采集的成功数据条数。对应源码 run 函数里 while suc_num < args["episode_num"] 的那个跳出条件。

use_seed: false

作用： 是否使用预先准备好的神仙种子。设为 false，系统就会开启第一阶段的盲摸探路；如果设为 true，系统会直接跳过第一阶段，去读 seed.txt。

save_freq: 15

作用： 数据采样频率。仿真世界的物理步长非常细微（比如 0.004 秒一步），如果每一步都存数据会导致文件极大。设为 15 意味着每隔 15 个物理步记录一次关节和相机状态。

embodiment: [aloha-agilex]

作用： 召唤的机械臂型号。这就是之前坑了 Piper 的那个参数！传入数组长度为 1，底层强制按双臂处理。

language_num: 1

作用： 任务结束后，调用大语言模型（或脚本）为当前动作生成多少条不同的自然语言描述（比如：“拿起锤子”、“抓住那个木柄”）。

🎲 2. 域随机化 (Domain Randomization)
这是强化学习从仿真走向现实（Sim2Real）的法宝。通过让环境充满随机性，防止 AI 模型死记硬背。

random_background: true / clean_background_rate: 0.2

作用： 开启后，桌子和地板的材质会随机变成木头、大理石、甚至奇怪的花纹。0.2 意味着有 20% 的概率保留干净的纯色背景。

cluttered_table: false

作用： 杂乱桌面。如果开启，桌上会随机刷出各种干扰物（比如杯子、扳手），专门用来锻炼机器人的避障能力。（初测关闭是为了降低物理引擎碰撞计算的压力）

random_light: false / crazy_random_light_rate: 0

作用： 光照随机化。开启后灯光的颜色、强度和位置会乱变。（极度消耗显存，所以为你这台 6GB 显卡关闭了）

random_head_camera_dis: 0 / random_table_height: 0

作用： 每次初始化时，相机位置和桌子高度的随机偏移量。0 表示完全固定。

📷 3. 摄影棚机位 (Camera)
head_camera_type: D435 / wrist_camera_type: D435

作用： 选用的虚拟相机型号。D435 对应了现实中 Intel RealSense D435 深度相机的内参（FOV、畸变等），让仿真图像更贴近真实的机器人硬件。

collect_head_camera: true / collect_wrist_camera: false

作用： 决定是否开启头顶的全局相机和手腕处的微距相机。因为双臂加上头顶一共会有 3 个相机，全开对 I/O 读写压力很大。

💾 4. 数据资产打包 (Data Type & I/O)
决定了 episodeX.hdf5 文件里到底装了什么“知识”。

rgb: true / depth: false / pointcloud: false

作用： 收集彩色图像。关闭深度图和点云。点云（Point Cloud）需要提取空间中所有物体的三维坐标点，计算量极其恐怖。

qpos: true / endpose: true

作用： 收集机器人的“肌肉记忆”。qpos 是每个电机关节的具体旋转角度，endpose 是机械臂最前端夹爪在空间中的 XYZ 坐标和四元数姿态。

pcd_down_sample_num: 1024 / pcd_crop: true

作用： 点云降采样参数（即使你关闭了点云，这里也需要有默认值）。把几十万个点精简到 1024 个，并裁掉桌子以外的无用点云。

save_path: ./data

作用： 文件的老家。

clear_cache_freq: 1

作用： 你机器的免死金牌！ 在 collect_data.py 的第二阶段，每录完 1 条数据，立刻命令 SAPIEN 引擎释放所有显存。

collect_data: true / eval_video_log: true

作用： collect_data 允许脚本进入第二阶段的正式录制。eval_video_log 则是命令 ffmpeg 把几百张图片合成为 episode0.mp4，这就是你刚才看到的视频来源。
